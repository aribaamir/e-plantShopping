# e-plantShopping

## Project Overview

e-plantShopping is an online plant shopping application that allows users to explore and purchase a variety of plants.

The application provides a user-friendly interface for browsing plants and managing an online shopping experience.

## Features
- Browse available plants.
- View plant details.
- Add plants to the shopping cart.
- Manage shopping cart items.
- Enjoy a simple and user-friendly shopping experience.

## Technologies Used
- React
- JavaScript
- HTML
- CSS
